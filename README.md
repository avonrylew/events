# EventEmitter Roadmap

Core Features
-------------
🧩 Strongly-Typed Events
🔄 Event Streams (map, filter, debounce, throttle, take, skip)
⚡ Async Support (emitAsync)
🛠 Listener Control (ttl, priority, max calls, prepend/append, once)
🔗 Piping & onAny
💾 Serialization (serialize / deserialize)
📝 Utility Methods (wait, race, listeners, names, count)
🧹 Disposal & Cleanup (dispose)

🧪 Typed Async Streams
🔝 Dynamic Listener Prioritization
🗂 Listener Metadata Exposure

⏪ Event History / Replay
🐞 Debug / Logging Tools
